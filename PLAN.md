# Пошаговый план

План для меня: что делать руками, что просить у ИИ и как проверять результат.
Требования лежат в [REQUIREMENTS.md](REQUIREMENTS.md), правила для ИИ — в [RULES.md](RULES.md).

**Ритм каждого шага:**
1. Новый чат с ИИ → прикрепить `README.md`, `REQUIREMENTS.md`, `RULES.md` → вставить промпт шага.
2. ИИ рассказывает план **без кода** → я упрощаю или подтверждаю.
3. ИИ пишет код → я **проверяю руками** по пункту «Проверка».
4. Работает → `git commit`. Сломалось → прошу починить; если ИИ зациклился → `git restore .` и начинаю шаг заново.

**Базовый промпт (начало каждого шага):**
> Прочитай README.md, REQUIREMENTS.md и RULES.md. Мы делаем шаг **X.Y** из PLAN.md. Сначала расскажи план простыми словами и предложи варианты, начиная с самого простого. Код не пиши, пока я не подтвержу. Задавай вопросы, если чего-то не хватает.

Отмечай выполненное галочками прямо в этом файле.
