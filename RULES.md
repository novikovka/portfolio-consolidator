# Правила для ИИ в этом проекте

1. Сначала объясни план простыми словами и дождись моего подтверждения. Не пиши код, пока я не скажу.
2. Предлагай несколько вариантов, начиная с самого простого.
3. Делай самый простой следующий шаг, который я могу проверить руками.
4. Меняй только то, о чём я попросила, и только в названных файлах. Если нужно тронуть другой файл, спроси.
5. Не дублируй код: сначала ищи готовое решение в проекте.
6. Соблюдай архитектуру из REQUIREMENTS.md: расчёты только в `core/`, SQL только в `storage/`, сеть только в `market/`, UI работает только через `services/`.
7. Деньги и количества — только `Decimal` в Python и `NUMERIC` в БД, никогда `float`.
8. Пароли и ключи — только в `.env`. Никогда не вставляй их в код.
9. После изменения скажи, как мне проверить результат, и какие тесты запустить.
10. Если не уверен в версии библиотеки или API, скажи об этом и попроси документацию.
11. Задавай вопросы, если чего-то не хватает, а не додумывай.
12. Разработка ведётся на Windows 10 (PowerShell), сервер — Raspberry Pi OS. Команды давай для нужной системы.
